🚀 Built Sush — a Voice-Enabled Telegram AI Shopping & Styling Assistant

I recently built an end-to-end AI automation that helps users search for products and get styling advice directly inside Telegram.

What it can do:

- Accept text and voice messages through Telegram
- Transcribe voice notes using Groq Whisper
- Use a Gemini-powered AI agent to understand shopping and styling requests
- Search Amazon India for products through ScraperAPI
- Return product suggestions or personalised styling guidance automatically

I built the workflow in n8n and tested it across multiple user scenarios. One interesting challenge was working within free-tier API and token limits while keeping the automation reliable.

This project taught me a lot about connecting AI models, APIs, voice input, and workflow automation into one useful user experience.
